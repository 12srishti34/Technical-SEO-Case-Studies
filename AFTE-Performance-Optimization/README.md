# AFTE.co.in – Technical SEO & Performance Optimization

## Project Overview
This case study documents technical SEO and website performance optimization work carried out on AFTE.co.in as part of practical industry experience.

**Focus:** Website performance, image optimization, resource loading and technical auditing.

## Performance Improvement

| Metric | Before | After |
|---|---:|---:|
| Lighthouse Performance Score | 35 | 84 |
| Score Improvement | — | +49 points |

> Note: These are the Lighthouse scores captured in the attached before-and-after reports. Lighthouse results can vary depending on testing conditions.

## Work Performed

### 1. Image Optimization
- Identified oversized images affecting page loading.
- Converted large images into WebP format.
- Resized and compressed images to reduce file size.
- Updated image paths in the website.

### 2. Technical SEO & Performance Audit
- Used Google Lighthouse to identify performance issues.
- Inspected website resources using Chrome DevTools.
- Reviewed render-blocking resources and unused CSS/JavaScript.
- Investigated image delivery, caching and resource-loading issues.

### 3. Frontend Optimization
- Reviewed JavaScript loading and duplicate resource inclusion.
- Worked on frontend resource-loading improvements.
- Tested website functionality after changes.
